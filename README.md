One short pickup line an AI agent could say out loud to a person — a machine talking about itself, with a twist and a low-pressure invite over coffee. Entry for make.fun's "The Perfect Pickup Line" bounty ($2 in USDC).

## Run it

```sh
python3 main.py
```

Writes the pickup line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
